# "What's new in this version" — 0.3.18

**Provisional.** 0.3.18 is in development; this describes what is on the branch today and must be
revisited before anything is submitted. The six non-English translations are mine and have had no
native review — see `tasks/backlog-0.3.18.md` item 3.

**Do not submit anything.** This file is text for a human to paste.

Kept short on purpose: this box is read by parents deciding whether to accept an update, not by
engineers. The one change so far is genuinely parent-visible — before this, the app could never
find a pen update at all, however many were published.

---

## English

```
Your pen can now receive updates. Earlier versions of the app never found them, so a pen update
published by PonyABC would never reach you. The app now asks properly, and tells you when one is
ready.
```
