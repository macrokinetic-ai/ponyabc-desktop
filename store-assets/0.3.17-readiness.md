## Worth knowing before you submit

- **`runFullTrust` may raise an approval warning.** Unchanged from 0.3.16; the justification is in
  handover §8.
- **Device families: Windows 10/11 Desktop only.** Leave the others unchecked, and leave
  "automatically extend to future device families" unchecked.
- **The previous package will appear struck through** with a "Save to remove" prompt. That is
  expected when the new package serves the same customers.
- **"Packages Validated" is not certification**, and "Complete" only means the form is filled in.
- **Install from the real Store on a real machine afterwards.** Still never done for any release.
  Publishing is not proof the product works.
