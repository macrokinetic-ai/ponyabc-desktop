準備 開始之前

  1. 安裝 PonyABC Desktop ，可於 Microsoft Store 免費下載（掃描二維碼）。
  2. 連接點讀錄音筆 ，請使用 可傳輸資料的 USB 線。只用藍牙並不足夠，有些線亦只供充電。
  3. 開啟程式。 首頁會顯示 「P5 點讀錄音筆已連接」。如未顯示，請按 重新偵測。
Microsoft Store

1 把書本放進點讀錄音筆

  1. 開啟 BOOK 資料庫。程式會用一句話說明有甚麼新內容，以及大約需時多久。
  2. 按 同步書本，不需要逐本挑選。
  3. 請保持點讀錄音筆連接電腦。 一本較大的書本約需二十分鐘。

1 ⋯然後重新開機

4.  見到 「完成！」時，請拔出點讀錄音筆，並 關機再開啟。第一次開機會稍慢，因為點讀錄音筆正在準備新書本。
空間不足？ 程式會先檢查，並告訴您尚欠多少空間。請先備份並刪除部分錄音，然後再同步一次。

2 保存孩子的錄音

  1. 開啟 我的錄音，然後按 備份我的錄音。副本會保留在這部電腦。
  2. 要放回錄音，請按 放回點讀錄音筆。如果該貼紙號碼已有錄音，可試聽兩段再選擇。
  3. 改名 可為錄音改一個您認得的名稱。

3 更新點讀錄音筆（Windows）

  1. 開啟 韌體 ，然後按指示操作。
  2. 請選擇 是 ，回應 Windows 的授權提示。
  3. 完成後，請將點讀錄音筆關機再開啟。
更新期間請勿拔出點讀錄音筆，也不要關閉程式。

4 更改語言

設定 → 介面語言 （八種語言）
