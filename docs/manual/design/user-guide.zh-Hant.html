1開始使用

歡迎使用。PonyABC Desktop 協助您照顧 P5 點讀錄音筆：把新書放進點讀錄音筆、為孩子的錄音保存副本，並讓點讀錄音筆本身保持最新。使用時不需要任何技術知識。

安裝程式

  1. 開啟 Microsoft Store （Windows 電腦內）。
  2. 搜尋 PonyABC Desktop，或掃描右方二維碼。
  3. 按 取得，然後按 開啟。之後不需要任何設定。
Microsoft Store

連接點讀錄音筆

請用點讀錄音筆隨附的 USB 線 接到電腦。只用藍牙並不足夠：點讀錄音筆必須在電腦上顯示為一個磁碟，而這只有用線連接才做得到。連接成功後，首頁會顯示 「P5 點讀錄音筆已連接」。

顯示「未連接」？請換一個 USB 插口或換一條線。有些線只供充電，無法傳輸資料。然後按 重新偵測。

2註冊您的點讀錄音筆

您的 P5 點讀錄音筆享有 一年保養 ，由購買日起計。登記只需一分鐘，日後如有問題，我們也能更快為您跟進。

請掃描二維碼、前往 register.ponyabc.uk，或在程式首頁按 註冊您的點讀錄音筆 。

掃描即可登記

3把書本放進點讀錄音筆

開啟 BOOK 資料庫。程式會用一句話說明點讀錄音筆有甚麼可以更新，例如：

點讀錄音筆內有 2 本 PonyABC 書本。可加入 2 本新書，另有 1 項更新。約需 14 分鐘。

按 同步書本，這樣就可以了。您不需要逐本挑選，也不會誤刪任何書本。

進行期間，請保持點讀錄音筆連接電腦。程式會顯示 「請勿拔出點讀錄音筆」、進度列和剩餘時間。

為甚麼需要一段時間？點讀錄音筆每秒只能寫入約 1 MB，所以一本較大的書本可能需要二十分鐘左右。程式會在開始前告訴您大約需時多久，過程中也會倒數。期間電腦不會進入睡眠，您可以先做別的事。

如果全部已是最新

畫面會顯示 「所有書本已是最新。」 不需要任何操作。想再檢查一次，隨時可按 檢查有沒有新書 。

4將點讀錄音筆關機再開啟

只要同步有把書本加入或更新，完成後都會顯示 「完成！」。

  1. 拔出點讀錄音筆。
  2. 將它 關機再開啟。
  3. 讓它開著，直到有反應為止。同步後的第一次開機會比平時慢，因為點讀錄音筆正在準備書本，並非當機。

在重新開機之前，新加入或剛更新的書本可能無法正常播放。

為甚麼每次都要？每當有書本加入或更新，點讀錄音筆都會在下次開機時重新整理自己的書本清單。關機再開啟，就能確保每本書都正常播放。

5點讀錄音筆空間不足時

程式會在複製任何內容 之前 先檢查空間，避免做到一半才出問題。空間不足時，程式會明確告訴您尚欠多少。

  1. 按 前往「我的錄音」。
  2. 把錄音備份到這部電腦。
  3. 從點讀錄音筆刪除不再需要的錄音。已備份的副本會安全保留在電腦上。
  4. 回到此頁，再按一次 同步書本 。
「無法檢查點讀錄音筆的剩餘空間」請拔出點讀錄音筆，重新插入後再試一次。程式寧可停下來，也不會憑猜測繼續。

6孩子的錄音

開啟 我的錄音。左邊是點讀錄音筆內的錄音，右邊是保存在這部電腦的備份。

備份我的錄音

按 備份我的錄音 ，把點讀錄音筆內的錄音全部複製到這部電腦。刪除任何錄音前，建議先做這一步。

放回點讀錄音筆

選擇一個備份，然後按 放回點讀錄音筆。如果該貼紙號碼已有錄音，程式會讓您試聽兩段再選擇保留哪一段，不會代您決定。

改名

為錄音改一個您認得的名稱，例如「媽媽唸的晚安故事」。名稱只儲存在這部電腦，點讀錄音筆一律使用貼紙號碼。

更改貼紙號碼

把錄音移到另一張貼紙。請照貼紙上印的號碼準確輸入，包括開頭的 0。

從點讀錄音筆刪除不用擔心：程式一定會先在電腦保存副本，才會刪除。

7更新點讀錄音筆（Windows）

點讀錄音筆本身的軟件偶爾需要更新。請開啟 韌體 ，然後按指示操作，程式會逐步引導您完成。

  • 過程中 Windows 會要求您授權，請選擇 是 ，否則更新無法繼續。
  • 更新期間請勿拔出點讀錄音筆，也不要關閉程式 。
  • 完成後，請將點讀錄音筆關機再開啟，並試播一本書。
「更新未有開始」如果更新在開始前就停下來——例如在 Windows 的提示中選了 否 ——程式會清楚告訴您，而點讀錄音筆不會有任何改動。請確認點讀錄音筆仍然連接，然後再試一次。

9遇到問題時

程式顯示未連接點讀錄音筆。請試換線的另一端、換一個 USB 插口，或換一條線。市面上有不少只供充電的線，無法傳輸資料。
新加入的書本無法播放。請將點讀錄音筆關機再開啟，並等它完成啟動。若仍然無法播放，請在連接點讀錄音筆的情況下開啟程式；如果出現 整理點讀錄音筆的書本清單，請按下它，然後再次重新開機。
程式顯示無法檢查剩餘空間。請拔出點讀錄音筆，重新插入後再試一次。
複製了很久仍未完成。這通常是正常的，一本較大的書本約需二十分鐘。進度列移動得慢，但確實在移動。
其他問題？請前往 設定 → 匯出診斷紀錄 ，並把儲存的檔案電郵給我們。檔案記錄了程式做過的事，有助我們判斷發生了甚麼。
